# Nexoryx Technical Specification & Implementation Log

## 1. Core Technology Stack
*   **Framework**: React 18.x with Vite for optimized build and HMR (Hot Module Replacement).
*   **Animations**: Framer Motion for hardware-accelerated UI transitions and micro-animations.
*   **Icons**: Lucide-React for a consistent, modern vector iconography.
*   **Routing**: React Router DOM for seamless navigation between Landing and Architect pages.
*   **Styling**: Custom Vanilla CSS with a global design system defined via CSS Variables (Root Tokens).

## 2. Architect Editor Implementation Details

### A. Video Engine & Synchronization
*   **Media Integration**: Native HTML5 `<video>` element controlled via React `useRef`.
*   **State Sync**: Centralized state management for `isPlaying`, `currentTime`, and `duration`.
*   **Metadata Processing**: Implemented `handleLoadedMetadata` to automatically fetch video length and sync it with the project's Storyboard (specifically Scene 1).
*   **Event Handling**: `onTimeUpdate` for real-time playhead tracking and timecode formatting (`mm:ss.ms`).

### B. Interactive Timeline System
*   **Dynamic Ruler**: Percentage-based coordinate system that scales with the total project duration (`totalDuration`).
*   **Tick Generation**: Automated generation of 1-second interval marks and 5-second interval timecode labels for high readability without overlapping.
*   **Coordinate Seeking**: Custom `handleTimelineClick` logic that maps mouse `X` coordinates to precise project timecodes:
    `seekTo = (clickX / containerWidth) * totalDuration`
*   **Smooth Playhead**: CSS-driven playhead movement with conditional transitions (`transition: none` during playback for zero-latency tracking).

### C. Storyboard & Scene Management
*   **Scene Architecture**: Component-based data structure where each scene contains prompts, durations, and unique identifiers.
*   **Logic Operations**:
    *   `addScene`: Incremental ID generation and auto-focus of new scenes.
    *   `deleteScene`: Filter-based removal with automatic active-scene fallback.
    *   `updateScene`: Immutable state updates for individual scene properties.
*   **Empty State Handler**: Robust conditional rendering for a "Blank Screen" state when zero scenes exist, featuring recovery CTAs (Call to Actions).

### D. Visual Refinement & Crop Engine
*   **Glassmorphism**: Advanced UI layering using `backdrop-filter: blur()`, semi-transparent borders, and high-contrast matte backgrounds.
*   **Crop Overlays**: Simulated cropping tool with common aspect ratio presets (16:9, 9:16, 1:1, 4:5).
*   **HSL Color System**: Custom primary tokens:
    *   `Indigo`: `hsl(239, 84%, 67%)`
    *   `Violet`: `hsl(263, 70%, 50%)`
    *   `Slate`: Digital matte finish for professional editor feel.

## 3. Implemented Logic Workflows

### 1. The "Save" Lifecycle
*   **State Machine**: `idle` -> `saving` -> `saved` -> `idle` loop.
*   **Visual Feedback**: Integrated CSS animations for loading spinners and success checkmarks within the primary action buttons.

### 2. Time/Width Mapping
*   **Scaling Algorithm**: Each scene block (`tl-block`) calculates its width relative to the larger of `videoDuration` or `projectDuration`:
    `widthPercentage = (sceneDuration / projectTotal) * 100`
*   **Consistency**: Ensured the Ruler, Tracks, and Playhead all subscribe to the same divisor to prevent visual drift.

## 4. UI/UX Refinements
*   **Overflow Handling**: Implemented `overflow-x: hidden` and `width: 100%` on timeline tracks to solve coordinate-precision issues during navigation.
*   **Hover States**: Contextual action icons (Delete/Crop) appear on scene cards only when hovered to maintain a clean, distraction-free environment.
*   **Agent Integration**: Dedicated sidebar for AI Director chat, styled with distinct bot/user bubbles and cinematic quick-action chips.

## 5. Performance Optimizations
*   **Callback Memoization**: `useCallback` used for heavy event handlers to prevent unnecessary re-renders during high-frequency video time updates.
*   **CSS Keyframes**: Offloaded animations (like the save spinner) to the browser's compositor thread using native CSS `@keyframes`.
